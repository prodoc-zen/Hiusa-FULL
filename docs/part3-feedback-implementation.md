# Part 3: submitted files and college oversight

The Department Head's college profile provides oversight of every student organization in that college. SAO approval no longer creates a Head profile in each student organization. After deployment, run `php artisan hiusa:consolidate-department-head-profiles` once to remove previously created redundant profiles. An unrelated student, officer, or Admin membership that was explicitly assigned to the same person is kept.

The Department Head Organizations, application, and approval rows use the shared three-dot action menu. **Submitted files** in the Head navigation shows the protected file index for organizations in the Head's college. The Head can view a file but cannot replace or delete it.

The Organization Admin's **Submitted files** page shows registration, compliance, event proposal, and financial report files for its organization, with status and protected view actions. A current compliance or registration document can be replaced or deleted from this page. Replacing resets that requirement to SAO review, preserves its registration classification, removes the previous physical file, and notifies SAO and the college Head. Deleting removes the compliance submission and file and notifies SAO, the Head, and other organization Admins. Event and financial supporting documents remain managed by their existing submission workflows so a finalized approval record is not silently changed.

The SAO Reviews > Compliance > Documents tab shows submitted files across organizations, including event and financial files still with the Department Head. It has server disk capacity, private-file usage, organization usage, and editable limits. SAO may delete an active organization's compliance file from the repository. The SAO per-file limit is 1–10 MB within the existing upload cap; the organization limit is 10–10,240 MB. Registration, compliance, event proposal, and financial-report uploads check the configured limits. Existing files remain after a limit is lowered; new uploads are refused if they exceed it. Draft or unsubmitted records are not part of the submitted-file repository.
